MVCG Prod - site (version finale)

À déployer (tout à la racine du site, au même niveau) :
- index.html              page complète : styles, scripts, polices et images intégrés
- favicon.ico, favicon.svg, apple-touch-icon.png, icon-192.png, icon-512.png, icon-maskable-512.png
- site.webmanifest         icône quand le site est ajouté à l'écran d'accueil d'un téléphone
- og-image.jpg            image affichée quand le lien est partagé (WhatsApp, Facebook, LinkedIn, X)

Le dossier sources/ n'est pas à mettre en ligne : il contient les images originales,
le code source (index.src.html) et le script qui assemble index.html (build.py).

IMPORTANT : adresse du site
Les balises de partage et de référencement utilisent l'adresse https://mvcg-prod.stwb.workers.dev
Si le site passe sur un autre domaine (ex. mvcgprod.com), remplacer cette adresse dans index.html
(rechercher « mvcg-prod.stwb.workers.dev » : 7 occurrences), puis redéployer.
Ensuite, tester le partage sur https://developers.facebook.com/tools/debug/ (bouton « Scrape again »).
